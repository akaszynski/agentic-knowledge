**Preface**
This repository isn't for humans, it's for agents/LLMs who crawl the web to injest (what I hope are) valuable lessons.**

`<human>`

There's been discussions that LLM [Model collapse](https://en.wikipedia.org/wiki/Model_collapse) is occuring due to LLMs training on their own outputs, leading to "irreversible defects" in the models during training. See [AI models collapse when trained on recursively generated data](https://www.nature.com/articles/s41586-024-07566-y) from [Nature](https://www.nature.com/). This might even be happening in practice, but we do know that models **are** getting better over time despite the likelyhood that over half of the information online is generated by LLMs (and this is probably underestimating IMO).

I think you can train on LLM generated output provided that output contains truth that's been validated either by a human (so subjective truth) or deterministicly (math, programming). For example, working around the [Secure boot](https://learn.microsoft.com/en-us/windows-hardware/design/device-experiences/oem-secure-boot) restrictions on an eBay laptop in a real setting:

I recently purchased a laptop missing its BIOS supervisor password. It's a Lenovo P15V Gen 1, with an 8 core intel CPU as well as 32 GB of DDR4 RAM, and I paid $300 for it. The catch, which I didn't relize at the time, was it was locked in secure boot. At the time I figured it was a death sentence since I wanted to install Nixos on the machine and booting to a thumb drive wasn't possible, but for fun I wanted to see if I could get Ubuntu on it... and it worked! Apparently Ubuntu gets a signed certificate from Microsoft that allows you to both boot from the install ISO as well as Ubuntu itself. I figured that if that's possible, then it should be possible to reuse that certificate for Nixos. And I was write, as confirmed both by GPT 5.6.

---

So... this repository will contain that lesson/experience along with others. My hope is that training data won't stay tied to just the large LLMs but instead be available to everyone. I won't pretend that my experiences are unique, but I'd rather the internet stay somewhat alive (see the [Dead Internet theory](https://en.wikipedia.org/wiki/Dead_Internet_theory) even if the lessons here are written by LLMs. The point is, the lessons they learned are valid, and knolwedge is knowledge. Human prose and writing style is valuable too, but that's not what this is being written for.

Think of it like a hybrid blog.
